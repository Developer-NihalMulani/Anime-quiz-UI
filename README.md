Anime Quiz Web App 🍥
A sleek, responsive anime trivia quiz web application built using HTML, CSS, Bootstrap, and JavaScript. Test your knowledge across various popular anime series with a clean UI and instant score tracking.

✨ Features
Responsive Design: Built with Bootstrap to ensure seamless playability across mobile devices, tablets, and desktops.

Interactive Gameplay: Dynamic question loading, immediate answer validation, and smooth state management using vanilla JavaScript.

Score Tracking: Keeps track of your correct answers and displays a final results summary at the end of the quiz.

Anime Theme: Styled with custom CSS to match an engaging anime aesthetic.

🛠️ Tech Stack
HTML5: Semantic markup structure for quiz containers, questions, and options.

CSS3: Custom styling, animations, and layout polishes.

Bootstrap: Responsive grid system, buttons, and utility classes.

JavaScript (ES6+): DOM manipulation, event handling, quiz logic, and score calculation.


💡 What I Learned
Building this project helped solidify several core web development concepts:

Manipulating the DOM dynamically using JavaScript (createElement, event listeners, and state toggles).

Structuring CSS layouts alongside Bootstrap components without layout conflicts.

Managing quiz data arrays and handling user selection logic conditionally.
